# 키보드 워리어 | 출시 MVP 기획서 v1.1

2026-11-23 · GPT Work 기획 / Cursor 구현 · 기준 자료는 FromGPT의 11월 23일 초안 및 화면 시안 8장이다. 아래에서 **확정**은 구현 계약이고 **파일럿**은 첫 플레이테스트를 위한 가정이다. 파일럿 수치 변경은 출시 정책 변경으로 간주하지 않는다.

## 플레이 경험과 공간

플레이어는 네온 원형 경기장에서 짧은 타자 대결을 반복한다. 상대보다 늦게 입력해도 자기 문제를 풀어 골드를 모으고, 본체·테두리·이펙트를 조합한 자기 발판을 다음 경기에서 보여준다. 학습을 원하는 플레이어는 문제 아래 뜻을 켜고 개인 연습을 선택할 수 있다.

**확정** 로비, 참가 원, 연습, 경기장, 결산과 상점은 Lobby Place 하나에 있다. 서버 최대 인원은 12명이다. 경기 시작 순간 원 안에 있는 1~12명이 참가하며 혼자서도 진행한다. 360도 원 위의 서로 다른 발판을 무작위 배정하고 시선을 중앙으로 향하게 한다. 원을 벗어나면 시작 전 대기를 취소한다. 참가 버튼 없이 월드 행동과 HUD 피드백으로 대기 여부를 알린다.

**경기장 규격** 외곽 지름은 100 studs다. 지름 12 studs인 원형 발판 12개를 같은 높이에서 30° 간격으로 배치한다. 인접 발판 가장자리 사이의 최단 거리는 4 studs다. 따라서 중심 배치 반지름은 16 / (2 × sin(15°)) ≈ 30.91 studs다. 참가 원의 지름은 Studio에 배치한 JoinZone에서 정한다.

| 구간 | 시간 | 플레이어 경험 | 서버 책임 |
|---|---:|---|---|
| 대결 | 120초 | 한 문제를 완료하면 자신의 다음 문제를 즉시 받는다 | 참가자·입력 언어 고정, 출제와 정답 순번 관리 |
| 마지막 구간 | 위 120초 중 마지막 30초 | x2 표시, 자신의 점수와 순위 변화 확인 | 경쟁 점수 2배. 최초 3명 보너스 없음 |
| 결산 | 30초 | 본인 순위·점수·플레이 언어·골드·경험치와 참가자별 언어 확인 | 결과 스냅샷 및 경기별 보상 확정 |
| 휴식 | 30초 | 원에서 다음 대결을 기다리거나 연습·상점 이용 | 다음 참가자 다시 판정 |

한 사이클은 180초다. **파일럿 제안** 서버를 열면 첫 휴식부터 시작한다. 빈 경기도 같은 시계로 진행하고, 늦게 들어온 사용자는 다음 시작까지 연습할 수 있다. 만원일 때는 원 안의 연속 대기 시작 시각 순, 같은 시각이면 UserId 순으로 선발한다. 완료 후 원 밖 대기 위치로 복귀한다. 이 정책은 첫 다인 테스트 후 확정한다.

## 출제·언어·점수

- 문제 ID는 의미 단위다. 같은 ID의 영어와 한국어는 같은 기본 점수와 등급 색상을 쓴다. 단어와 문장을 모두 출제한다. 각 참가자는 독립적으로 다음 문제로 진행한다.
- UI 표시 언어, 타자 언어, 뜻 표시 언어를 별도로 취급한다. 영어 타자는 뜻 표시 끔, 그 외 타자는 영어 뜻이 기본이다. 대결 시작 시 타자 언어를 고정한다. PC 다국어의 첫 검증 데이터는 영·한이며 출시 언어 목록은 검수 후 확정한다.
- 모바일 가로는 영문 QWERTY A–Z, Space, Backspace, Enter만 제공한다. 자동 정답과 Enter는 동일한 완료 요청 경로를 사용한다. PC 물리 키보드와 공통 서버 판정을 사용하며 한글 IME 조합 중 제출을 보류한다.
- **파일럿 제안** 동일 순서의 문제 ID를 사용하고 영문 대소문자를 접어 비교한다. 가운데 공백은 유지한다. 미완성 Enter는 현재 문제를 유지한다. 오타 수정은 허용한다. 문제를 발급할 때 서버 잔여 시간이 0초 초과 30초 이하면 x2를 고정한다. 종료 후 접수는 마감한다. 이 경계 정책은 플레이테스트에서 HUD 안내와 함께 검토한다.
- **파일럿 제안** 동점은 해당 점수에 먼저 도달한 순, 그마저 같으면 UserId 순으로 정렬한다. 입력 정확도·속도는 참고 기록으로 둔다. 콤보 점수 배율은 적용하지 않는다.

## 성장·상점·랭크

단어 정답, 문장 정답, 경기 완료에 골드를 지급한다. 정상 완료자의 경험치는 순위와 무관하게 같다. 파일럿에서는 점수 x2가 골드에 영향을 주지 않는다. 서버는 정답 보상을 세션에 누적하고 결산에서 완료 보상을 한 번만 더한다. 연습은 점수 경쟁과 분리하며 연습 보상은 파일럿에서 끈다.

상점은 **발판 본체 / 발판 테두리 / 발판 이펙트** 세 탭이다. 카드를 고르면 임시 조합으로 3D 미리보기를 갱신한다. 구매 전에는 영구 장착 데이터를 바꾸지 않는다. 구매 완료 후 보유 상태와 바로 장착 동작을 표시한다. 장착은 한 부위만 바꾼다. 골드 상품과 Robux 상품을 계획하며 실제 가격·상품 유형·플랫폼 ID 확정 후 개방한다. 랭크는 전체 랭크 한 종류다. 글로벌 단일 경기 최고점은 파일럿 후보이며 시즌·티어·패스는 출시 범위에서 제외한다.

독립 화면을 열면 좌측 로비 HUD를 숨긴다. 닫을 때 현재 경기 상태가 로비 HUD 표시를 허용하는지 다시 계산한다. 시안의 보라색 패널과 발판, 청록색 강조, 중앙 문제·하단 키보드를 시각 기준으로 삼는다. 시안 속 임의 상품, Robux 잔액, 시즌, 추가 메뉴는 기능 요구사항에 포함되지 않는다.
