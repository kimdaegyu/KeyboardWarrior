# 점수 타이틀과 발판 꾸미기

## 획득과 보상

정식 경기를 완주하면 서버가 확정한 그 경기의 최종 점수로 모든 업적을 검사한다. 조건은 단일 경기 점수 ≥ Score이다. 새로 달성한 모든 ID를 오름차순으로 개방하고, 각 ShopId의 Rim을 영구 소유 목록에 추가한다. 새 타이틀과 Rim은 계정당 한 번씩 지급한다. 연습과 중도 퇴장은 대상에서 제외한다. 출시 이전 기록은 소급 지급하지 않고 업데이트 후 첫 완주부터 판정하는 안이다.

## 장착과 표시

기본 모드는 자동이다. 여러 개를 얻으면 보유 ID 중 가장 높은 하나를 장착한다. 플레이어가 보유 타이틀을 직접 선택하면 수동 모드와 선택 ID를 저장한다. 이후 업적 획득, 재접속, 리스폰에도 해당 선택을 유지한다. 타이틀 선택 UI에서 ‘자동 장착’을 선택하면 현재 최고 ID를 즉시 장착한다. 장식용 Rim은 지급만 하고 기존 Rim 장착은 유지한다.

서버가 플레이어의 EquippedTitleId를 복제하고 각 클라이언트가 로비, 경기 워프, 플레이, 결과에서 자신과 다른 플레이어에게 해당 TitleKey를 현지화해 표시한다. 단계가 바뀌거나 발판으로 워프해도 타이틀을 지우지 않는다. 기준은 HumanoidRootPart다. 이름 하단은 머리의 기본 자세에서 2스터드 위이며, Idle·고개 흔들림·제자리 동작과 걷기의 관절 움직임은 따라가지 않는다. 점프처럼 몸 중심이 오르내리면 타이틀도 함께 움직인다. 이름·타이틀 두 줄 BillboardGui와 거리 100스터드를 기준으로 한다. 착용 중인 타이틀 글자는 닉네임 위에 가운데 정렬로 두고, 그 글자 바로 앞에 행의 itemId 아이콘을 둔다. 타이틀 미보유자는 기존 이름 표시를 유지한다.

이번 정산에서 새로 얻은 타이틀만 점수·보상 아래에 표시한다. 타이틀마다 현지화된 이름과 지급된 Rim 이름을 한 줄에 배치한다. 720점 첫 완주는 3줄, 이후 700점 완주는 0줄, 이후 900점 완주는 새 타이틀 1줄이다. 첫 완주 1,500점은 10줄 전체를 스크롤로 확인한다. 닫기 버튼과 다음 경기 타이머를 가리지 않는다.

## 데이터 계약과 가격

AchievementDataSheet의 첫 시트는 Id, TitleKey, Score, ShopId, RobloxBadgeId, itemId 순서다. ShopId는 ShopDataSheet의 문자열 Id를 직접 참조한다. itemId는 ItemDataSheet의 아이콘 ID이며 타이틀 1부터 10은 10080부터 10089다. 배지 ID는 미입력 상태로 두며 배지 API 호출을 생략한다. 추후 입력 시 엑셀 정밀도 손실을 피하도록 텍스트로 입력한다. 타이틀·상품명 원본은 src/localization/CoreStrings.csv의 영어 Source 및 ko다.

ShopDataSheet의 Color는 0~255 정수 세 개를 세미콜론으로 구분한다. 기존 6개 ID·가격·공개 범위를 유지한다. starter_rim과 starter_effect의 0;0;0은 형식상 값으로, 두 기본 ID는 테두리·파티클을 생성하지 않는다. 다른 검정색 상품에도 이 예외를 적용하지 않는다.

출시용 Body와 Effect는 각 10종의 Gold 상품이다. Body 가격은 100~2,000 Gold, Effect는 150~2,250 Gold로 설정한 초기 밸런스안이다. Rim 10종은 Currency=Achievement, Price=0이며 개별 점수 업적으로만 해금된다. 기존 기본·Studio 상품은 이 집계에서 제외한다. 상점 미리보기, 장착 발판, 경기 중 쌓이는 발판 모두 같은 RGB를 사용한다. 보상 Rim은 미소유 시 필요 점수를 표시하고, 소유하면 장착할 수 있다.
