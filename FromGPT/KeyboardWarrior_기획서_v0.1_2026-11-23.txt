키보드 워리어 (KEYBOARD WARRIOR)
게임 기획서 / Game Design Document
버전: v0.1 (기획 정리본)
작성 기준일: 2026-11-23 (KST)
문서 성격: 지금까지의 대화에서 확정된 내용을 정리한 개발 착수용 초안

======================================================================
0. 문서 사용 원칙
======================================================================
[확정] 사용자가 명시적으로 확정하거나 이후 수정 없이 채택한 주요 기획
[방향] 논의된 추천안이나 이미지 시안에 반영되었지만 세부 확정이 필요한 내용
[미정] 개발 전에 결정해야 하는 값, 예외 상황, 운영 규칙

※ 이미지 시안은 시각적 참고자료이다. 시안에 등장한 임의의 버튼, 재화, 캐릭터 판매,
   시즌 랭킹, 랭크 티어, 가격, 점수 등은 이 문서의 [확정] 사항보다 우선하지 않는다.
※ 실제 코드와 DataStore의 현 상태를 조사한 결과를 기록한 문서는 아니다.

======================================================================
1. 프로젝트 개요
======================================================================
[확정]
- 게임명: 키보드 워리어 (Keyboard Warrior)
- 플랫폼: Roblox
- 장르: 다인원 실시간 타자 경쟁 + 개인 타자 연습 + 발판 꾸미기
- 플레이 방식: 단어·문장을 빠르고 정확하게 입력하여 점수를 경쟁한다.
- 경기 최대 참가 인원: 30명
- Roblox Place 구성: Lobby Place 1개만 사용한다.
- 대상 화면: 모바일 가로 화면 우선. 같은 GUI를 PC/태블릿에서 반응형으로 확대·조정한다.
- 반복 플레이 동기: 경기 점수/순위, 레벨/경험치, 골드 획득, 발판 꾸미기 아이템 수집.

[기획 핵심 가치]
- 2분짜리 짧은 대결을 여러 번 반복할 수 있는 빠른 플레이.
- 30개의 발판을 둘러싼 원형 경기장에서 다른 플레이어와 함께 경쟁하는 시각적 재미.
- 유저가 선택한 언어로 입력하고 다른 언어의 뜻을 함께 보며 학습하는 경험.
- 경쟁 순위가 낮아도 경기 참가·완료 보상 및 골드로 꾸미기를 진행할 수 있는 구조.

[개발 범위 원칙]
- 출시 속도를 우선한다.
- 공통 UI 1세트를 기본으로 제작한다. PC·모바일용 별도 화면을 이중 개발하지 않는다.
- 시즌 패스, 별도 인벤토리, 친구 전용 메뉴, 별도 '꾸미기' 메뉴는 제작하지 않는다.
- 게임 전용 Place를 추가하지 않으며, 경기 참가/연습/결과/상점이 한 Place에서 진행된다.

======================================================================
2. 전체 게임 루프 및 경기 시간
======================================================================
[확정] 총 3분(180초) 주기로 한 번의 경기 사이클을 반복한다.

   ① 대결: 120초 (2분)
      - 참가한 사용자들이 각자의 문제를 입력해 점수를 획득한다.
      - 대결 마지막 30초(남은 시간 00:30부터 종료까지): 점수 2배(x2).

   ② 결산: 30초
      - 최종 순위, 점수, 플레이 언어, 골드, 경험치 등 결과를 표시한다.

   ③ 휴식: 30초
      - 다음 대결을 준비하고 상점·연습 등 대기 활동을 할 수 있다.

   이후 다음 3분 사이클 시작.

[확정]
- 현재 상태(대결/결산/휴식) 및 남은 시간을 화면에 표시한다.
- 경기 중 플레이 언어 변경은 불가능하다.
- 다음 경기 참가 여부는 시작 시점의 참가 조건을 기준으로 결정한다.

[미정]
- 새로운 서버 생성 직후 3분 사이클의 첫 시작 시점.
- 참가자가 0명일 때도 대결 시간을 그대로 흘릴지 여부.
- 경기 중 늦게 접속한 사용자는 다음 경기부터 참가하도록 제한할지 여부.
- 서버에서 타이머를 운영할 때의 재시작/복구 정책.

3. Lobby Place, 참가 원, 30인 경기장
======================================================================
[확정]
- 서버에 입장하면 동일한 Lobby Place에 나타난다.
- 로비에는 '경기 참가 원'이 있다.
- 사용자가 원 안에 있으면 다음 경기 시작 시 자동 참가한다.
- 원에 들어가는 행동이 참가 신청이다. 별도 '참가하기' 팝업이나 참가 버튼은 없다.
- 경기 참가를 원하지 않는 사용자는 원 밖에서 개인 연습을 할 수 있다.
- 경기 참가자는 시작 시 30개의 개인 발판 중 하나를 무작위로 배정받는다.
- 발판 30개는 360도 원형 배치이며, 플레이어는 발판 위에서 경기장 중앙을 바라본다.
- 최대 참가 수는 30명이다. 30명이 모이지 않아도 경기는 진행 가능한 구조를 지향한다.

[방향]
- 원 안에 들어오면 '다음 경기 참가 대기 중'을 즉시 표시한다.
- 원 밖으로 나오면 시작 전 참가 상태가 취소된다.
- 경기 중에는 각 플레이어가 자신의 발판에 고정되어 타이핑에 집중한다.
- 참가 인원 수 / 30명, 다음 경기 시작까지 남은 시간을 로비에 표시한다.
- 이미 참가한 사용자는 다음 경기에도 쉽게 이어서 참가할 수 있도록 한다.

[미정]
- 한 경기 종료 후 참가 원 내부로 복귀시키고 자동 참가 대기를 유지할지 여부.
- 결산·휴식 중 월드 이동을 언제부터 허용할지.
- 참가 원의 반지름, 경계 중첩 판정, 인원 30명 도달 시 피드백.
- 경기 중 연결이 끊기거나 재접속한 유저의 복귀 방식.

4. 출제 규칙 / 타자 입력 / 정답 처리
======================================================================
[확정]
- 한 번에 하나의 단어 또는 문장만 출제한다.
- 사용자가 현재 문제를 정답 처리하면 즉시 다음 문제가 등장한다.
- 사용자별로 문제 진행 속도가 독립적이다. 다른 사람이 완료할 때까지 기다리지 않는다.
- 단어/문장마다 기본 점수가 있다.
- 문제 점수에 따라 문제 프레임의 배경·색상이 달라진다. 사용자는 색상으로 점수를 인지한다.
- 가장 먼저 입력한 3명에게 보너스를 주는 규칙은 제거한다.

[방향]
- 문장은 실제 사용 언어의 문장 길이에 따라 가독성 있게 줄바꿈한다.
- 점수 등급 색상은 상점 꾸미기 아이템을 장착해도 식별 가능하도록 유지한다.
- 실수한 문자는 수정 가능하게 하고 불필요한 점수 감점은 피한다.
- 입력 완료 시 정확도·속도와 문제 ID를 기록한다.
- 콤보는 있다면 점수 배율이 아닌 시각 연출 및 개인 기록 용도로 사용한다.

[미정]
- 단어:문장 출제 비율(기존 70:30은 제안값이며 미확정).
- 점수별 등급 수, 색상 코드, 점수표, 문제 길이와 난이도 기준.
- 문제 순서: 모든 참가자에게 동일한 문제 ID 순서를 줄지 여부(공정성 측면에서 권장).
- 영문 대소문자 구분, 공백·문장부호·오타 수정 세부 정답 규칙.
- Enter를 수동 확정에도 사용할지, 자동 정답 완료 시 입력 확정/다음 문제 이동을 어떻게 처리할지.
- 문제 Skip 허용 여부와 페널티.

5. 언어 정책
======================================================================
[확정]
- 문제는 사용자가 선택한 '타자 입력 언어'로 표시한다.
- 의미가 같은 문제 ID를 언어별로 현지화한다.
  예: 하나의 문제 ID가 한국어 사용자에게 '사과', 영어 사용자에게 'Apple'로 보인다.
- 번역 언어(뜻 표시 언어)는 타자 언어와 별도로 선택할 수 있다.
- 기본 번역 언어 정책:
    · 타자 언어 = 영어: 번역 기본값 '표시 안 함'
    · 타자 언어 = 영어 이외: 번역 기본값 '영어'
- 입력 언어별 점수 보정은 초기 버전에 적용하지 않는다.
- 동일 문제 ID에는 입력 언어와 무관하게 동일 기본 점수를 부여한다.
- 서비스 이후 언어별 플레이 성과를 측정해 유불리를 확인하고 필요하면 조정한다.
- 경기 진행 중 입력 언어를 변경할 수 없다. 경기 시작 전에 선택된 언어를 사용한다.
- 실시간 경기 랭킹의 각 플레이어 행에 해당 플레이어의 입력 언어를 표시한다.
- 경기 결과의 각 플레이어 행에도 해당 플레이어의 입력 언어를 표시한다.
- 본인 경기 결과 요약에도 '플레이 언어'를 별도 표시한다.

[확정: 플랫폼별 입력 지원]
- PC: 다국어 타자 입력을 지원하는 방향.
- 모바일: 첫 출시에서는 전용 영문 터치 키보드만 제공한다(영어 타자 입력만 가능).
- 모바일에서도 표시 UI 언어·번역 언어는 타자 입력 언어와 별도로 설정할 수 있다.
- PC/모바일은 동일 경기장에서 함께 플레이 가능하며 초기에는 동일 점수 규칙을 사용한다.

[미정]
- PC 타자 입력 지원 언어의 최종 목록과 우선 구현 순서.
- 각 언어의 문장부호, 공백, 특수문자 및 IME 판정 규칙.
- 언어별 입력 길이 차이의 운영 보정 기준(일단 보정하지 않음).
- 타자 언어 전환 시 저장·적용 시점(다음 경기부터 적용을 기본 방향으로 권장).

======================================================================
6. 모바일 영문 전용 키보드
======================================================================
[확정]
- 모바일 UI는 가로 화면을 기본으로 한다.
- 스마트폰에서 대결 및 개인 연습을 할 때 게임 내 전용 영문 QWERTY 키보드를 표시한다.
- 지원 버튼: 영문 A~Z, Space, Backspace, Enter.
- Shift 버튼 없음.
- 숫자 전환(123), 숫자·기호 키보드 전환, 별도 특수문자 전환 없음.
- 영문 자동 정답 판정 방식이며 Enter 버튼은 반드시 포함한다.

[구현 유의]
- 모바일 출제 데이터는 전용 키보드로 입력 가능한 문자열만 사용해야 한다.
- 글자 입력에 따른 자동 정답 완료와 Enter 처리의 중복 점수 지급을 막는다.
- 키보드 터치 영역을 충분히 확보하고 가장 작은 지원 가로 화면에서도 입력 가능해야 한다.
- PC는 물리 키보드 입력을 사용하되 점수·정답 처리 로직은 모바일과 공통화한다.

[미정]
- 자동 정답 순간에 Enter를 누른 경우의 동작(중복 완료 방지 필요).
- Enter의 역할: 수동 제출/확인/다음 문제 이동 중 무엇을 보조할지 세부 확정.
- 사용자 지정 키보드 배치·키 반복 입력 처리 여부.

======================================================================
7. 점수와 실시간 랭킹
======================================================================
[확정]
- 각 문제마다 정해진 기본 점수를 지급한다.
- 모든 입력 언어는 해당 문제 ID에 같은 점수를 지급한다(초기 언어별 보정 없음).
- 최초 정답자 1~3등 보너스는 없다.
- 경기 종료 30초 전부터 점수 2배가 적용된다.
- HUD에 실시간 순위와 점수를 표시한다.
- 실시간 순위의 모든 표시 행에는 각 플레이어의 입력 언어를 함께 표시한다.
- 대결 결과의 순위표에도 각 사용자별 입력 언어가 표시된다.

[방향]
- 좁은 모바일 화면에서는 TOP 5와 내 순위를 기본 표시하고, 전체 30명은 확장 또는 스크롤로 확인한다.
- 순위표의 권장 열: 순위 / 아바타·닉네임 / 언어 코드 / 점수.
- 본인 점수 및 순위 변동을 쉽게 확인할 수 있게 강조한다.
- 콤보가 존재하더라도 점수 보너스는 주지 않는 방향을 권장한다.

[미정]
- 동일 점수일 때 순위 결정 기준.
- 최종 30초 x2 배율 판정 시점(악용 방지를 위해 '문제 출제 시점 고정' 권장).
- 실시간 랭킹 업데이트 주기 및 전체 순위 화면 확장 방식.
- 개인 기록에 정확도, CPM/WPM, 콤보를 어디까지 포함할지.

======================================================================
8. 경기 결과 화면
======================================================================
[확정]
- 30초 결산 구간에 결과를 표시한다.
- 본인 최종 순위 및 최종 점수.
- 이번 경기에 사용한 본인의 플레이 언어.
- 최종 순위표에서 전체 참가자 각각의 플레이 언어.
- 경기에서 획득한 골드와 경험치.
- 한 Place 안에서 다음 경기로 이어지므로 '로비로 이동'용 Place 텔레포트 버튼은 없다.

[방향]
- 경기 종료 요약에 정확도, 평균 타자 속도, 개인 기록 갱신 여부를 함께 표기한다.
- 우측 순위표의 권장 열: 순위 / 닉네임 / 플레이 언어 / 최종 점수.
- 전체 30명 참가 시 리스트는 스크롤로 확인할 수 있다.
- 다음 경기 대기 상태 및 남은 시간을 명시한다.

[미정]
- 경기 결과 UI 하단에 '다시 참가', '다음 경기 대기' 버튼이 실제로 필요한지 여부.
  (참가 원 기반 자동 참가와 충돌하지 않도록 설계해야 한다.)
- 결산 화면이 열린 동안 상점을 열 수 있도록 할지 여부.
- 동점/중도 퇴장/입력 없음 사용자에 대한 표시 방식.

======================================================================
9. 레벨, 경험치, 골드
======================================================================
[확정: 경험치]
- 정상적으로 한 판을 클리어한 모든 참가자는 순위와 관계없이 동일한 경험치를 획득한다.
- 경험치가 일정량 쌓이면 레벨이 상승한다.
- 상위 랭커에게 경험치 가산 보너스를 부여하는 규칙은 현재 기획에 없다.

[확정: 골드]
- 단어 정답 시 골드를 획득한다.
- 문장 정답 시 골드를 획득한다.
- 한 판 완료 시 골드를 추가 획득한다.
- 골드는 꾸미기 상품을 구입하는 게임 내 기본 재화이다.

[방향]
- 초보자도 골드를 얻을 수 있도록 경기 완료 보상 비중을 확보한다.
- 비정상적 장시간 방치(AFK)로 경기 완료 보상만 반복 획득하지 않도록 최소 활동 조건을 둔다.
- 마지막 30초 점수 x2는 경쟁 점수에만 적용하고 골드는 2배로 지급하지 않는 방향을 권장한다.
- 개인 연습에서의 골드 지급은 초기에는 제외하는 방향을 권장한다.

[미정: 반드시 밸런싱할 수치]
- 단어/문장/경기 완료 각각의 골드 지급량.
- 경기 완료 경험치 및 레벨별 필요 경험치.
- 레벨 보상 여부 및 구체적인 보상 아이템.
- 최소 활동 조건(완료 문제 수/유효 입력/연결 해제 시 정책).
- 골드 보유 상한, 지급 제한, 부정 입력 제재 정책.

※ 과거 대화의 '단어 1G, 문장 4G, 경기 50G' 등은 예시 수치이며 확정 가격표가 아니다.

10. 상점 / BM / 발판 꾸미기
======================================================================
[확정: 상점의 기능]
- 로비 메뉴에 '상점' 버튼 하나만 둔다.
- 별도 '꾸미기' 버튼, 인벤토리 버튼, 친구 버튼을 두지 않는다.
- 상점 하나에서 상품 구매, 보유 확인, 미리보기, 장착을 모두 처리한다.
- 상점은 '발판 꾸미기' 전용이다. 캐릭터는 판매하지 않는다.
- 상점 카테고리는 정확히 다음 3개 탭이다.
    ① 발판 본체
    ② 발판 테두리
    ③ 발판 이펙트
- 발판 본체 + 테두리 + 이펙트를 조합해 자신의 발판을 꾸민다.
- 골드 상품과 Robux 상품을 판매하는 방향이다.
- 시즌 패스는 만들지 않는다.

[확정: 구매/장착 구조]
- 상점에서 보유 여부와 장착 중 상태를 알아볼 수 있어야 한다.
- 상품 구매 전에 실제 발판 조합을 미리볼 수 있어야 한다.
- 구매 후 바로 해당 아이템을 장착하는 흐름을 제공한다.
- 장착 정보는 아이템 카테고리별로 구분하여 관리한다.

[방향: UI 레이아웃]
- 좌측: 발판 본체/테두리/이펙트 3개 탭과 상품 목록.
- 우측: 현재 선택 아이템이 적용된 내 발판 3D 미리보기.
- 우측 하단: 구매/보유/장착 중 상태에 맞는 버튼.
- 현재 조합(본체, 테두리, 이펙트)을 보여준다.
- 상품 가격, 골드/Robux 화폐 구분, 적용 부위 및 아이템명을 표시한다.
- 한 부위만 교체해도 다른 부위는 유지한다.
- 미리보기는 실제 장착 상태를 변경하지 않는다.

[현재 범위에서 제외]
- 캐릭터 판매 / 캐릭터 스킨 카테고리.
- 별도 인벤토리 또는 별도 꾸미기 화면.
- 친구 전용 버튼.
- 시즌 패스, 시즌 전용 상점.
- 상점의 별도 타자 SFX 상품 탭(현재 최종 확정 카테고리는 발판 3종뿐임).

[미정]
- 각 카테고리 상품 수, 상품 ID, 정확한 골드/Robux 가격, 유료/무료 배치.
- 발판 외형 진화, 색상 패턴, 소모성 연출, 시즌별 꾸미기 컬렉션의 후속 도입 여부.
- 과거 논의한 '타자 SFX/타자 이펙트 판매'를 후속에 재검토할지 여부.
- 골드 직접 구매 허용 여부(현재 확정되지 않음).

11. GUI 및 HUD 공통 정책
======================================================================
[확정]
- UI는 처음부터 모바일 가로 기준으로 설계한다.
- PC와 태블릿에 별도 복제 UI를 만들지 않고 화면 크기·비율에 따라 반응형으로 조절한다.
- 로비 좌측 메뉴는 '개인 연습', '상점', '랭크', '설정' 중심으로 구성한다.
- 우상단 햄버거 메뉴는 제거한다. 설정 진입은 로비의 '설정' 버튼으로 처리한다.
- 별도 '꾸미기', '인벤토리', '친구', '시즌 패스' 메뉴는 없다.
- 상점, 개인 연습, 랭크, 설정, 튜토리얼 등 독립 GUI를 열었을 때에는 로비 좌측 HUD 버튼들을 OFF/숨김 처리한다.
- GUI가 닫히면 표시 가능한 로비 상태에서 좌측 HUD를 다시 표시한다.
- 대결 중에는 입력 언어를 변경하는 UI를 제공하지 않는다.
- 설정 화면에서는 그래픽 품질 관련 항목을 제거한다.

[방향]
- 상단 상태 표시줄: 게임 로고, 현재 레벨/경험치, 골드, Robux 보유·상태 등.
- GUI가 열렸을 때 로비 HUD와 겹치지 않도록 Safe Area 및 ZIndex 관리.
- 모바일 터치 대상의 최소 크기와 비율이 바뀌는 화면에 대응한다.
- 실제 화면 비율이 16:9를 벗어나도 빈 공간을 자연스럽게 사용하고 필수 요소가 잘리지 않게 한다.

12. 화면별 요구사항 (총 8종)

12-1. HUD [로비]
[확정]

[방향]

12-2. 상점
[확정]
- GUI 열림 상태이므로 로비 좌측 HUD 숨김.
- 캐릭터 판매 없음.
- 발판 본체 / 발판 테두리 / 발판 이펙트 정확히 3개 탭.
- 상품 선택, 골드/Robux 가격, 보유 상태, 미리보기, 구매, 장착.
[방향]
- 3D 미리보기 및 현재 착용 조합 정보가 항상 확인 가능하도록 구성.

12-3. 개인 연습
[확정]
- 참가 원에 들어가지 않아도 타자 연습 가능.
- 단어·문장 타자 연습을 제공한다.
- 모바일은 전용 영문 A~Z/Space/Backspace/Enter 키보드를 사용한다.
- GUI가 열린 동안 로비 좌측 HUD 숨김.
[방향]
- 입력 문제, 뜻(번역), 정답·오답·정확도·타자 속도 등 이번 연습 기록 표시.
- 언어 설정과 연습 모드 선택은 연습 시작 전에 처리한다.
[미정]
- 연습 레벨, 시간 제한, 골드/경험치 지급 여부(초기 지급 제외 권장).

12-4. 타자 대결
[확정]
- 30개 발판 원형 경기장에서 중앙을 바라보는 시점.
- 단어 또는 문장 한 개와 번역, 입력창, 모바일 전용 키보드.
- 현재 경기 시간/진행 상태, 마지막 30초 x2 점수 강조.
- 실시간 랭킹: 보이는 모든 플레이어 행에 입력 언어를 표시.
- 본인 입력 언어도 별도로 표시하지만 경기 중 변경은 불가.
[방향]
- 실시간 랭킹 TOP 5+내 순위 기본표시; 전체 랭킹 스크롤/확장 가능.
- 점수 등급 색상은 단어/문장 프레임에 적용.

12-5. 게임 결과
[확정]
- 결산 30초 동안 표시.
- 본인 최종 순위/점수/플레이 언어, 획득 골드/경험치.
- 순위표의 모든 참가자 행에 플레이 언어 표시.
- Lobby Place 안에서 처리하며 별도 Game Place/로비 이동 버튼 없음.
[방향]
- 정확도, 평균 속도, 개인 최고 기록 갱신 연출.

12-6. 랭크
[확정]
- '기록' 메뉴의 명칭은 '랭크'.
- 랭크 화면에는 '전체 랭크' 하나만 존재한다.
- 시즌 랭크 없음, 랭크 티어/등급 시스템 없음.
- GUI가 열린 동안 로비 좌측 HUD 숨김.
[방향]
- 전체 랭크 표: 순위 / 플레이어 / 최고 점수 등 기본 정보.
- 자신의 순위와 최고 기록 강조.
[미정]
- 전체 랭크 산정 기준(역대 단일 경기 최고 점수, 평균 점수 등 최종 확정 필요).
- 랭크 집계 범위(서버별이 아닌 게임 전체 글로벌 랭킹인지) 및 갱신 주기.

12-7. 튜토리얼
[확정]
- 첫 접속 시 게임 이용 방법을 안내한다.
- 참가 원 자동 참가, 개인 연습, 상점, 경기 흐름을 안내한다.
- 상점 내용은 발판 본체/테두리/이펙트만 설명한다.
- 튜토리얼에서 별도 꾸미기/인벤토리/친구 버튼을 설명하지 않는다.
- GUI가 열린 동안 로비 좌측 HUD 숨김.
[방향]
- 단계별 안내, 이전/다음/건너뛰기, 다시 보지 않기.
- 대결 2분 → 결산 30초 → 휴식 30초, 마지막 30초 점수 x2 소개.
- 모바일 키보드 A~Z/Space/Backspace/Enter 소개.

12-8. 설정
[확정]
- 햄버거 메뉴 없이 로비의 설정 버튼으로 열기.
- 그래픽 품질 설정 제거.
- 경기 중 입력 언어 변경 불가.
- 모바일 타자 입력은 영어만 가능.
- GUI가 열린 동안 로비 좌측 HUD 숨김.
[방향]
- 타자 입력 언어, 번역 언어, UI 언어 등의 구분을 명확히 한다.
- BGM/SFX 음량, 진동, 닉네임 표시, 튜토리얼 다시 보기 등 실용 기능 위주.
- 설정 저장/닫기 및 입력 언어 적용 시점 안내.

13. 게임 데이터 및 시스템 구성(설계 방향)
======================================================================
[방향: 신규 프로젝트]
- 기존 Roblox 'Look At You' 게임을 직접 정리·복제하기보다 신규 게임 프로젝트로 제작한다.
- 기존 프로젝트에서 분석·추출한 CoreTemplate 공통 기능을 복사해 재사용하는 방식을 채택한다.
- 핵심 공통 기능 후보: Localization, DataStore.
- 기존 게임 전용 유닛·전투·스테이지 데이터는 가져오지 않는다.
- 기존 운영 DataStore를 참조하거나 수정하지 않도록 저장소 이름·키를 분리한다.

[권장 모듈 책임]
- MatchService: 3분 사이클 상태 및 타이머, 참가자 확정, 경기 종료.
- ArenaService: 원 진입·이탈 판정, 발판 30개 랜덤 배정, 중앙 방향 배치.
- QuestionService: 문제 ID/언어별 텍스트/번역/점수·등급/출제 순서.
- TypingService: 입력 상태, 정답 완료, 서버 검증 및 부정 입력 감지.
- ScoreService: 기본 점수 및 마지막 30초 x2, 실시간 순위 계산.
- RewardService: 문제별/경기 완료 골드, 경기 완료 경험치, 보상 중복 방지.
- ShopService: 발판 상품 구매, 소유권, 골드 차감, Robux 구매 권한 확인.
- CosmeticService: 발판 본체/테두리/이펙트 보유 및 장착 상태.
- RankingService: 전체 랭크 데이터 집계/조회.
- UIController: 공통 GUI 열기/닫기 및 로비 좌측 HUD 가시성 제어.

[문제 데이터 예시 필드]
- QuestionId, Kind(Word/Sentence), Score, Grade, TextByLocale, MeaningByLocale,
  InputCharConstraints, Enabled.
- '같은 의미의 문제'를 QuestionId 하나로 묶어 언어별 결과를 비교한다.

[유저 데이터 예시 필드]
- Level, Exp, Gold, Settings(UI locale / typing locale / translation locale),
  OwnedPlatformBodies, OwnedRims, OwnedPlatformEffects,
  EquippedPlatformBody, EquippedRim, EquippedPlatformEffect,
  PersonalBestScore, PersonalPracticeStats.
- 실제 컬렉션 자료형 및 DataStore SchemaVersion은 구현 시 확정한다.

[주의]
- 본문 구조는 제안 아키텍처이다. 실제 Look At You 소스 분석과
  CoreTemplate 이식 결과로 파일명·호출 API가 달라질 수 있다.

14. 서버 권한 / 부정행위 / 저장 안전성
======================================================================
[필수 설계 사항]
- 클라이언트가 임의 점수, 골드, 경험치를 지정해 서버에 지급하도록 하지 않는다.
- 서버가 문제 ID, 정답 검증, 출제 시점, 완료 시점, 점수, 완료 상태를 관리한다.
- 문제 완료 요청의 중복·재전송·순서 위조를 방지한다.
- 비정상적으로 짧은 입력 시간 및 반복 요청 패턴을 기록·검토한다.
- 실제 물리 키 입력 여부를 서버가 완벽히 증명할 수 없다는 점을 인정하고 탐지·운영 대책을 둔다.
- 골드 구매 요청의 잔액/소유 상태를 서버에서 재검증한다.
- Robux 영구 아이템은 Roblox 플랫폼 소유권 확인과 실제 게임 저장 기록을 적절히 연계한다.
- 아이템 구매/골드 차감은 중복 요청 또는 저장 실패 시 불일치가 생기지 않게 한다.
- 단어 완료마다 DataStore를 호출하지 않고 서버 내 누적 및 안전한 저장 정책을 사용한다.
- 테스트 서버와 운영 데이터 저장소를 분리한다.

18. 최종 확정 사항 요약(개발 지시 기준)
======================================================================
- Lobby Place 하나, 최대 30인.
- 3분 주기: 2분 대결 + 30초 결산 + 30초 휴식.
- 경기 시작 시 참가 원 내부에 있으면 자동 참가. 별도 참가 버튼 없음.
- 개인 연습 가능. 30개 발판은 원형 배치, 랜덤 배정, 중앙을 보도록 배치.
- 단어/문장 1개씩 출제. 클리어하면 즉시 다음 문제.
- 단어/문장별 점수 및 점수별 프레임 색상.
- 언어별 점수는 동일. 최초 정답 3명 보너스 없음.
- 마지막 30초에는 경쟁 점수 x2.
- 참여자가 한 판 완료하면 모두 동일 경험치. 단어/문장/경기 완료에 골드 지급.
- PC 다국어 타이핑 방향, 모바일 첫 출시는 영어 전용 터치 키보드.
- 모바일 키보드: A~Z, Space, Backspace, Enter만.
- 게임 중 입력 언어 변경 불가. 입력 언어와 번역 언어는 별도 설정.
- 실시간 랭킹과 결과 전체 참가자 행에 '플레이 언어' 표시.
- 모바일 가로 기준 단일 UI, PC/태블릿에 반응형 확대·조절.
- 좌측 로비 HUD: 개인 연습 / 상점 / 랭크 / 설정.
- 햄버거 메뉴 제거. 다른 GUI를 열면 로비 좌측 HUD 숨김.
- 상점은 구매/보유/미리보기/장착 통합, 탭은 본체/테두리/발판 이펙트 3개.
- 상점에 캐릭터 상품 없음. 별도 꾸미기/인벤토리/친구 메뉴 없음.
- 시즌 패스 없음. 랭크는 전체 랭크만(시즌/티어 없음).
- 설정에 그래픽 품질 없음.
- 결산은 같은 Place에서 진행하며 별도 '로비로 이동' 기능 없음.
